# Integration-tester reports

One report per run of the independent integration tester, which checks the
code against `specs/SPEC.md` without knowing how it was written. Name:
`YYYY-MM-DD_<mode>_<commit>.md` (mode `incremental` or `full`). Each report
ends with a "Triage for the project" table; findings are fixed through the
block protocol, correcting `specs/SPEC.md` first when a finding shows the
spec was wrong.
