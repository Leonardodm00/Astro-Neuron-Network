GiuliaGate -- Giulia's new campaign (MODE=Full): neurons fixed at the default
cell, astrocytes with the contact gate, on the 37-D default pipeline
==========================================================================
Folder (decided 2026-10-31): this folder of the git clone on davinci,
  /davinci-1/home/ldellamea/ANN/Astro-Neuron-Network/hpc/Phenomenological_finalv1/GiuliaGate/
The launch package comes with git. The pipeline is copied in from the clone's
own hpc/Phenomenological_finalv1/ folder (step 0) and patched in place; the
copies and the campaigns stay out of git (.gitignore). Never run
"git clean -x" in the clone: it deletes ignored files.
Full procedure and the reasons behind each setting:
project doc claude/GiuliaGate_Campaign_Operations.md. Spec: specs/SPEC.md Block 9.

THIS FOLDER (repository path hpc/Phenomenological_finalv1/GiuliaGate/)
  prior_config.tsv        THE PRIOR: one row per axis (free with a box, or fixed
                          with a value) plus the conn_prob and gate boxes
  apply_prior_patch.py    the only reader of the TSV: patches the free boxes into
                          HPC_main_sweep.py, prints the freeze list and the
                          topology boxes, checks a patched file
  apply_freeze_patch.py   adds --freeze to the folder's HPC_main_sweep.py copy
  launch_GG.sh            launcher, login node; every campaign setting
  submit_GG.sh            PBS worker; never qsub it directly
  seed_alloc.py           seed allocator; its guard covers every launch folder under ~/ANN
  smoke_test_gg.py        checks of the package on a fresh copy (no simulation
                          unless --sim)
  APPLY_GG.txt            this file
  .gitignore              keeps the pipeline copies, campaign_*/ and artifacts/ out of git

DECIDED 2026-10-31 (by the author; operations doc section 2):
  neurons: the default cell, every neuron axis fixed at its registry value
    except Sigma, free in [2, 10] mV (linear)
  synapses: U_0_ar, U_max, Omega_f_ar (the asynchronous release) fixed;
    g_ampa and g_nmda free in [0.05, 10] nS; EC50_ampa, EC50_nmda fixed
  astrocytes: O_beta, O_3K, Omega_5P and C_Theta fixed; I_bias, F, U_A, G_T,
    O_N free in the registry boxes
  conn_prob U[0.05, 0.4] per network; the contact gate p U[0.2, 1] per network
    (as MEAMA); 180 s per simulation; 1200 neurons and 1200 astrocytes per
    mm^2 on a 300 um well (108 + 108)
  15 free axes in all; the range check on four nodes before the launch.

KNOWN PROBLEM, 2026-10-31 (specs/SPEC.md section 8): with the model as it is,
the astrocytes go non-finite (NaN) about 27 ms into a Full run, at nominal
parameters too, and stay so: no astrocyte events, no gliotransmission. The
neurons are unaffected. A fix is proposed and waits for the author's decision.
Until it is in, the range check's astrocyte outcomes and the campaign's
astrocyte axes carry no information: do not launch step 9 before it.
